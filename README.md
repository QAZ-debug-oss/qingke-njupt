# 轻课 · 南邮课表

无广告的个人课表网页应用，支持 Safari 书签、iPhone 主屏幕与离线访问。公开代码不内置个人课程、教室或上课安排。

## 上传与发布

1. 将本文件所在目录的全部内容上传至 `QAZ-debug-oss/qingke-njupt` 仓库根目录，确保根目录下直接有 `index.html`，并保留 `vendor` 文件夹。
2. 进入仓库 Settings → Pages，选择 Deploy from a branch，分支 main，文件夹 / (root)，保存。
3. 等待 GitHub Pages 构建完成，以设置页显示的 Visit site 地址为准。此仓库的默认地址应为 https://qaz-debug-oss.github.io/qingke-njupt/ ，未完成构建前可能显示404。

上传的是解压后的文件，不是把 ZIP 文件本身作为网页入口上传。

## 手机上使用

在 Safari 打开发布地址。到“导入”中选择自己的 JSON 课表备份，预览后保存。建议再次导出备份后，通过 Safari 共享菜单选择“添加书签”或“添加到主屏幕”。首次打开需联网，缓存完成后可离线查看。

主屏幕应用与浏览器的存储行为可能随 iOS 版本而变化。若主屏幕版本未带入修改，可重新导入 JSON 备份。清理浏览器数据或更换手机前应先备份。

## 课程数据

课程和修改仅保存在当前浏览器。支持 Excel（.xlsx）、HTML课表、CSV/TSV 与 JSON 备份；导入文件在本机解析。课程名称、星期、节次、周次、教室可编辑。

支持个人备份生成的 `#import=...` 链接，片段在本机解析，成功保存后从地址栏移除；已有本地课表时先预览。完整导入链接包含课表数据，应只在自己的设备间传递。

## 南邮导入的范围

学校登录由用户在南邮官方页面完成，本应用不收集学校账号密码。已实现常见课程明细和网格表格的本地导入，但南邮登录后的真实导出文件仍待专门验证；没有自动登录或实时同步。

纯静态，无构建步骤与远程脚本依赖。JSZip 许可证见 `vendor/JSZip-LICENSE.txt`。
